# DRUSHYANTH — Personal Portfolio

A cinematic editorial portfolio for Drushyanth, built with React, TypeScript, Vite and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

The production files are generated in `dist/`, ready for static hosting such as Hostinger.

## Direction

Digital creator · developer · brand builder.

The experience is intentionally dark, editorial, motion-led and responsive, with Kannada typography used as a subtle cultural layer.
